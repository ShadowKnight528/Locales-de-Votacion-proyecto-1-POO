# Locales-de-Votacion-proyecto-1-POO
Instrucciones de uso:

- Crear un nuevo proyecto java e incluir un paquete de nombre package_00
- Dentro del paquete importar las clases desde github
- En el archivo module-info.java incluir la instrucción requires java.desktop;
- Compilar y ejecutar el programa
- El proyecto cuenta con dos sedes ya inicializada que tienen por ID 2 y 3 respectivamente
- Ambas sedes cuentan con una mesa ya inicializada, para ambos casos el número de mesa es 1
- Ambas mesas cuentan con un votantes ya inicializado
